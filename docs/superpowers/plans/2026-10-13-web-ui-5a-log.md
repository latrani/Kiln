# Web UI step 5a: log mode — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The page has the TUI's log mode for a character. It shows the history with times and day rules, lets you select lines with the mouse, and supports find, go to date, copy, export (a download), and showing a line's tags. A hint row or prompt sits in the bottom pane. Ctrl+L, the `Log` chip, `/log` and Esc open and close it. The filter panel (`f`) is 5b.

**Architecture:**
- **Go:** part 2 already has log mode's actions (`log`, `log_close`, `range`, `extend`, `exclude`, `find`, `find_older`, `goto_date`, `copy`, `export`, …) and events (`Log`, `LogLines`). It gains:
  - `LogAt`: where find or go-to-date landed, which the API drops today by passing `nil` callbacks;
  - `find_newer`, `tags`, `export_name` and `say` actions;
  - `ExportFormat` on `Log`.
- **The page:**
  - `log.ts` holds the TUI's rules for rows, find status and keys as pure functions;
  - the store keeps each character's page-side log state (hidden by Ctrl+L, the prompt, where find landed);
  - `LogView` draws the lines in the main area;
  - `LogBar` draws the hints or prompt in the bottom pane;
  - the top bar and status line show find and selection, as the TUI's do.

**Tech Stack:** Go (internal/app, internal/feed, internal/webapi, internal/ui for one shared helper), Preact + TypeScript (web/ui), node:test with preact-render-to-string, headless Chrome smoke (web/smoke).

**Spec:** `docs/superpowers/specs/2026-10-12-web-ui-design.md`. This plan covers step 5, "Log mode", first half. The relevant parts are "For you to check" 3 (log mode's letters only while the log has focus; no `j k m space`), "Keys" (Ctrl+L), "Accessibility" (log mode has no live region), and "Order of work" 5.

## For you to check

These are the calls that change what someone sees or does. Everything else copies the TUI (`internal/ui/browse.go`, `view.go`'s top bar and status line).

1. **Selecting lines is by mouse,** as the spec says. A click selects a line; Shift+click extends the range, or inside it takes that line out (or back in); a click on the gutter `▌` takes it out too; dragging selects a run, as text selection does. These are the TUI's own mouse rules. There's no cursor and no `m`/`space` (spec).
2. **Keyboard selection:** Ctrl+A in the log selects every loaded line. Beyond that, keyboard users select with the browser's text selection (Shift+arrows with caret browsing), which the page reads as a range. I can't do better without the cursor the spec dropped. Say if you want one.
3. **The hint row is a web string:** `click to select · shift-click extends · / find · n/N · g date · t tags · e export · c copy · esc back` (5b adds `f filter`).
4. **Find steps from where you are.** The web has no cursor, so "where you are" is the last line find or go-to-date landed on, else the last line you clicked, else the newest. `n` goes older and `N` newer, as in the TUI.
5. **`t` shows the tags of that same line,** and with nothing clicked, the newest line's.
6. **Export asks for the format, then the file name, as the TUI does,** and then downloads. The suggested name is the TUI's (`export_name`), without a directory: the browser decides where downloads go.
7. **Ctrl+L hides log mode and keeps it as it was** (selection, find, prompt), as in the TUI. Esc closes it.
8. **Ctrl+O, Ctrl+T, Alt+T and `/edit` while log mode shows** say "Exit log mode first", as the TUI's picker does. (The TUI refuses the picker there; the editor opens over the picker, so it's refused too.)

```go
// LineTags says which tags a line has and, for each one without a style
// of its own, whose style it takes (styled is the character's
// highlighter's Styled): what log mode's t shows.
func LineTags(tags []string, styled func(tag string) (string, bool)) string {
	if len(tags) == 0 {
		return str.BrowseNoLineTags()
	}
	parts := make([]string, len(tags))
	for i, tag := range tags {
		switch s, ok := styled(tag); {
		case !ok:
			parts[i] = str.BrowseTagUnstyled(tag)
		case s != tag:
			parts[i] = str.BrowseTagAs(tag, s)
		default:
			parts[i] = tag
		}
	}
	return str.BrowseLineTags(strings.Join(parts, str.Separator()))
}
```

```go
package webapi

import "github.com/latrani/Kiln/internal/app"

// LogAt says where a find, a step (n, N) or go-to-date landed in log
// mode, for the page to show: line Seq. It can come a turn or more after
// the action, once older days are read.
type LogAt struct {
	Key string
	Seq int
}

// ExportName is the file name an export in Format starts with: no
// directory, since the browser decides where downloads go.
type ExportName struct{ Key, Format, Name string }

// land is the callback for where k's log mode lands: it queues a LogAt
// for the turn it happens in (see Run).
func (l *Loop) land(k string) func(*app.LogLine) {
	return func(ln *app.LogLine) { l.landed = append(l.landed, LogAt{Key: k, Seq: ln.Seq}) }
}

// takeLanded is the LogAt events queued since the last turn was sent.
func (l *Loop) takeLanded() []any {
	out := l.landed
	l.landed = nil
	return out
}
```

```ts
export const exportFormats: Record<string, string>; // p a h → plain ansi html
```

```ts
// shows, find's status and marks, and its keys. Lines are addressed by
// their number (Seq); one Go names that the page doesn't hold (not yet
// loaded) is nothing.
import type { LineData } from "./store.ts";
import * as str from "./str.gen.ts";

// LogState is Go's Log event (feed.Log).
export interface LogState {
  Key: string; Open: boolean; Find: string; Status: string; StatusErr: boolean;
  Searching: boolean; Loading: boolean; HistDone: boolean;
  Start?: number | null; End?: number | null; Selected: number;
  Excluded?: number[] | null; Hidden?: number[] | null; Matches?: number[] | null;
  ExportFormat: string;
}

// LogRow is one row of log mode: a day's rule, or a line with its marks.
export type LogRow =
  | { kind: "day"; day: string; label: string }
  | { kind: "line"; line: LineData; selected: boolean; excluded: boolean; match: boolean };

// logRows is what log mode shows of lines, oldest first: the lines the
// filter shows, a rule before each day's first, each marked in the range
// (start to end by place; a start alone is just itself), excluded, or a
// find match.
export function logRows(lines: LineData[], g: LogState): LogRow[] {
  const hidden = new Set(g.Hidden ?? []), excluded = new Set(g.Excluded ?? []), matches = new Set(g.Matches ?? []);
  const at = (seq: number | null | undefined) => (seq == null ? -1 : lines.findIndex((l) => l.Seq === seq));
  const s = at(g.Start), e = g.End == null ? s : at(g.End);
  const rows: LogRow[] = [];
  let day = "";
  lines.forEach((l, i) => {
    if (hidden.has(l.Seq)) return;
    if (l.Day !== day) {
      day = l.Day;
      rows.push({ kind: "day", day, label: l.DayLabel ?? day });
    }
    const selected = s >= 0 && e >= 0 && i >= Math.min(s, e) && i <= Math.max(s, e);
    rows.push({ kind: "line", line: l, selected, excluded: selected && excluded.has(l.Seq), match: !!g.Find && matches.has(l.Seq) });
  });
  return rows;
}

// findStatus is find's place for the top bar, as the TUI's FindStatus:
// the term and which match at is, counted from the newest, of how many
// (+ while older history may hold more); while it reads older days, how
// far back it's got.
export function findStatus(g: LogState, at: number | undefined, lines: LineData[]): string {
  if (!g.Find) return "";
  if (g.Searching) return str.browseSearching(g.Find, lines[0]?.Day ?? "");
  const ms = g.Matches ?? [];
  const k = at === undefined ? -1 : ms.indexOf(at);
  const i = k < 0 ? 0 : ms.length - k;
  return g.HistDone ? str.browseFindStatus(g.Find, i, ms.length) : str.browseFindStatusMore(g.Find, i, ms.length);
}

// segments splits text at every match of term, literally and ignoring
// case, as app.FindRE.
export function segments(text: string, term: string): { text: string; match: boolean }[] {
  if (!term) return [{ text, match: false }];
  const re = new RegExp(term.replace(/[.*+?^${}()|[\]\\]/g, "\\$&"), "giu");
  const out: { text: string; match: boolean }[] = [];
  let last = 0;
  for (const m of text.matchAll(re)) {
    if (m.index! > last) out.push({ text: text.slice(last, m.index), match: false });
    out.push({ text: m[0], match: true });
    last = m.index! + m[0].length;
  }
  if (last < text.length || out.length === 0) out.push({ text: text.slice(last), match: false });
  return out;
}

// LogKey is what a key does in log mode.
export type LogKey = "find" | "older" | "newer" | "date" | "export" | "copy" | "tags" | "all" | "back";

const letters: Record<string, LogKey> = { "/": "find", n: "older", N: "newer", g: "date", e: "export", c: "copy", t: "tags", Escape: "back" };

// logKey is a key in log mode, as the TUI's browseKeys less its cursor
// keys (spec); Ctrl+A (Cmd+A on a Mac) selects every loaded line.
export function logKey(e: { key: string; ctrlKey: boolean; altKey: boolean; metaKey: boolean }): LogKey | undefined {
  if ((e.ctrlKey || e.metaKey) && !e.altKey && e.key.toLowerCase() === "a") return "all";
  if (e.ctrlKey || e.altKey || e.metaKey) return undefined;
  return letters[e.key];
}
```

```ts
// logAct does what a log-mode key asks, as the TUI's browse.key: a
// prompt for find, a date or export's format; n and N step find from
// where it last landed (else the line last clicked, else the newest); c
// copies; t says the tags of that same line; Ctrl+A selects every loaded
// line; Esc stops a search, else closes log mode.
export function logAct(store: Store, does: LogKey): void {
  const s = store.state, k = s.active, g = s.logs[k] as LogState, v = s.logView[k] ?? { goN: 0 };
  const lines = s.logLines[k]?.lines ?? [];
  const here = v.at ?? v.clicked ?? lines.at(-1)?.Seq ?? -1;
  const act = s.act ?? (() => {});
  switch (does) {
    case "find": store.setLogView(k, { prompt: { kind: "find", value: g.Find } }); break;
    case "date": store.setLogView(k, { prompt: { kind: "date", value: "" } }); break;
    case "export": store.setLogView(k, { prompt: { kind: "format" } }); break;
    case "older": act({ Do: "find_older", Key: k, Seq: here }); break;
    case "newer": act({ Do: "find_newer", Key: k, Seq: here }); break;
    case "copy": act({ Do: "copy", Key: k }); break;
    case "tags": if (here >= 0) act({ Do: "tags", Key: k, Seq: here }); break;
    case "all": if (lines.length) act({ Do: "range", Key: k, Start: lines[0].Seq, End: lines.at(-1)!.Seq }); break;
    case "back":
      if (g.Searching) act({ Do: "stop_search", Key: k });
      else act({ Do: "log_close", Key: k });
      break;
  }
}
```

```tsx
import { useEffect, useLayoutEffect, useRef } from "preact/hooks";
import { tagsFor } from "../look.ts";
import { logAct, logKey, logRows, segments } from "../log.ts";
import type { LogState } from "../log.ts";
import type { State, Store } from "../store.ts";
import * as str from "../str.gen.ts";
import { roleClass } from "../theme.ts";
import { Line } from "./Line.tsx";

// seqOf is the line number of the log row holding node n, if any.
function seqOf(n: Node | null): number | undefined {
  const el = (n instanceof Element ? n : n?.parentElement)?.closest<HTMLElement>(".lrow");
  return el ? Number(el.dataset.seq) : undefined;
}

// LogView is log mode in the main area, as the TUI's: the history,
// oldest first, a rule before each day, each line's time and gutter (the
// range's ▌, an excluded line's ░), find's matches marked. Nothing is
// read aloud: it's history (spec). The mouse selects as the TUI's: a
// click takes a line, Shift+click extends the range (or inside it takes
// a line out or back), a click on the gutter takes a line out; dragging
// selects a run, as text selection does. Its letters work while it has
// focus (spec). Near the top it asks for older history, keeping your
// place; find and go-to-date bring their line into view.
export function LogView({ state, store }: { state: State; store: Store }) {
  const k = state.active;
  const g = state.logs[k] as LogState;
  const v = state.logView[k] ?? { goN: 0 };
  const lines = state.logLines[k]?.lines ?? [];
  const tags = tagsFor(state.theme, k);
  const el = useRef<HTMLDivElement>(null);
  const act = state.act ?? (() => {});

  useEffect(() => el.current?.focus(), [k]);
  // Opened at the newest line, as the TUI's cursor starts there.
  useLayoutEffect(() => {
    if (el.current) el.current.scrollTop = el.current.scrollHeight;
  }, [k]);
  // Find and go-to-date bring their line into view, once per landing.
  useLayoutEffect(() => {
    if (v.at !== undefined) el.current?.querySelector(`[data-seq="${v.at}"]`)?.scrollIntoView({ block: "center" });
  }, [v.goN]);

  const onScroll = () => {
    const e = el.current!;
    if (e.scrollTop < e.clientHeight && !g.Loading && !g.HistDone) act({ Do: "log_older", Key: k });
  };
  const onClick = (e: MouseEvent) => {
    if (window.getSelection()?.isCollapsed === false) return; // a drag: onMouseUp took it
    const seq = seqOf(e.target as Node);
    if (seq === undefined) return;
    const inRange = (e.target as Element).closest(".lrow")?.querySelector(".gutter")?.textContent !== " ";
    if (e.shiftKey && g.Start != null && g.End != null && inRange) act({ Do: "exclude", Key: k, Seq: seq });
    else if (e.shiftKey && g.Start != null) act({ Do: "extend", Key: k, Seq: seq });
    else if ((e.target as Element).closest(".gutter") && inRange && g.End != null) act({ Do: "exclude", Key: k, Seq: seq });
    else act({ Do: "range", Key: k, Start: seq, End: seq });
    store.setLogView(k, { clicked: seq });
  };
  // A drag selects the lines it covers, as a range.
  const onMouseUp = () => {
    const sel = window.getSelection();
    if (!sel || sel.isCollapsed || !el.current?.contains(sel.anchorNode)) return;
    const a = seqOf(sel.anchorNode), b = seqOf(sel.focusNode);
    if (a !== undefined && b !== undefined) {
      act({ Do: "range", Key: k, Start: a, End: b });
      store.setLogView(k, { clicked: b });
    }
  };
  const onKeyDown = (e: KeyboardEvent) => {
    const does = logKey(e);
    if (!does) return;
    e.preventDefault();
    logAct(store, does);
  };

  return (
    <main class="body">
```

```go
	"github.com/latrani/Kiln/internal/str"

// TestLog uses log mode the way a person does: Ctrl+L, a click and a
// shift-click, find, Esc out of a prompt, copy, export (a download), and
// Ctrl+L hiding it as it was.
func TestLog(t *testing.T) {
	ws, _ := launch(t)
	ev := evaluator(t, ws)
	waitFor(t, ev, `kilnPage.events.some(e => e.type === "Worlds")`, "the worlds")

	// Second, connected, with a line or two from the fake MUCK.
	ctrlO(t, ws)
	filter := `document.querySelector('.bottom input[role="combobox"]')`
	waitFor(t, ev, `document.activeElement === `+filter, "the filter")
	devtools(t, ws, "Input.insertText", map[string]any{"text": "sec"})
	pressKey(t, ws, "Enter", 13)
	waitFor(t, ev, `kilnPage.events.some(e => e.type === "Lines" && e.Key === "fake/second" && e.Lines.some(l => l.Kind === "server"))`, "Second's lines")

	// Ctrl+L: log mode, focused, its hints below, the chip lit.
	ctrlL := func() {
		for _, typ := range []string{"rawKeyDown", "keyUp"} {
			devtools(t, ws, "Input.dispatchKeyEvent", map[string]any{"type": typ, "key": "l", "code": "KeyL", "windowsVirtualKeyCode": 76, "modifiers": 2})
		}
	}
	ctrlL()
	logEl := `document.querySelector(".log")`
	waitFor(t, ev, `document.activeElement === `+logEl+` && document.querySelector(".lrow")`, "log mode, focused, with lines")
	waitFor(t, ev, `document.querySelector(".bottom").textContent === `+jsString(str.WebLogHints()), "the hints")

	// A click selects a line; a shift-click on another extends the range.
	rows := `[...document.querySelectorAll(".lrow")]`
	click(t, ws, ev, rows+`[0]`)
	waitFor(t, ev, rows+`[0].querySelector(".gutter").textContent === `+jsString(glyph.Selected), "the first line selected")
	shiftClick(t, ws, ev, rows+`.at(-1)`)
	waitFor(t, ev, rows+`.every(r => r.querySelector(".gutter").textContent === `+jsString(glyph.Selected)+`)`, "the range runs to the last line")

	// / opens find; typing goes to the prompt, not log mode's letters;
	// Enter finds; Esc in a prompt closes only the prompt.
	ev(logEl + `.focus()`)
	devtools(t, ws, "Input.dispatchKeyEvent", map[string]any{"type": "keyDown", "key": "/", "text": "/", "code": "Slash", "windowsVirtualKeyCode": 191})
	devtools(t, ws, "Input.dispatchKeyEvent", map[string]any{"type": "keyUp", "key": "/", "code": "Slash", "windowsVirtualKeyCode": 191})
	waitFor(t, ev, `document.activeElement === document.querySelector("#kiln-logprompt")`, "find's prompt")
	devtools(t, ws, "Input.insertText", map[string]any{"text": "fake muck"})
	if got := ev(`kilnPage.sent.some(a => a.Do === "find_older" || a.Do === "copy")`); got != "false" {
		t.Error("typing in the prompt ran log mode's letters")
	}
	pressKey(t, ws, "Enter", 13)
	waitFor(t, ev, `kilnPage.events.some(e => e.type === "LogAt" && e.Key === "fake/second") && document.querySelector("mark")`, "found, marked")
	waitFor(t, ev, `document.querySelector("header").textContent.includes(`+jsString(str.BrowseFindStatus("fake muck", 1, 1))+`)`, "the find status: one match, today's the only day")

	// c copies (the effect reaches the page); e, then h, then Enter:
	// a download of the export.
	ev(logEl + `.focus()`)
	for _, k := range []string{"c", "e"} {
		devtools(t, ws, "Input.dispatchKeyEvent", map[string]any{"type": "keyDown", "key": k, "text": k})
		devtools(t, ws, "Input.dispatchKeyEvent", map[string]any{"type": "keyUp", "key": k})
	}
	waitFor(t, ev, `kilnPage.events.some(e => e.type === "Effect" && e.effect === "Copy")`, "copied")
	waitFor(t, ev, `document.querySelector(".logbar").textContent.includes(`+jsString(str.BrowseFormatPrompt())+`)`, "export's format prompt")
	devtools(t, ws, "Input.dispatchKeyEvent", map[string]any{"type": "keyDown", "key": "h", "text": "h"})
	devtools(t, ws, "Input.dispatchKeyEvent", map[string]any{"type": "keyUp", "key": "h"})
	waitFor(t, ev, `document.querySelector("#kiln-logprompt") && document.querySelector("#kiln-logprompt").value.endsWith(".html")`, "the file name, suggested")
	pressKey(t, ws, "Enter", 13)
	waitFor(t, ev, `kilnPage.events.some(e => e.type === "Effect" && e.effect === "SaveFile")`, "the download")

	// Ctrl+L hides it, the input back; Ctrl+L again shows it as it was.
	ctrlL()
	waitFor(t, ev, `!document.querySelector(".log") && document.activeElement === document.querySelector(".bottom textarea")`, "hidden, the input back")
	ctrlL()
	waitFor(t, ev, `document.querySelector("mark")`, "back as it was")

	// Esc closes it.
	ev(logEl + `.focus()`)
	pressKey(t, ws, "Escape", 27)
	waitFor(t, ev, `!document.querySelector(".log") && kilnPage.events.filter(e => e.type === "Log").at(-1).Open === false`, "closed")
}
```
